# Учебные фотографии

Четыре оригинальные сцены созданы встроенным инструментом `image_gen` для English Studio. Полноразмерные изображения скомпонованы горизонтально. Сайт раздаёт WebP размером 1020 × 680 пикселей.

| Файл | Что видно и что можно обсудить |
| --- | --- |
| [bridge.webp](../public/media/field/bridge.webp) | Настил бетонного моста, две вертикальные опоры в реке и открытый пролёт. Подходит для *deck*, *pier* и описания пространства *under the deck*. |
| [commute.webp](../public/media/field/commute.webp) | Пассажирка ждёт под стеклянным навесом с проездным в руке. Красный трамвай подъезжает к платформе. Подходит для *transit pass*, *shelter*, *pull into the stop*. |
| [handover.webp](../public/media/field/handover.webp) | Два инженера держат раскрытый чертёж моста за разные края. На бумаге видны сгибы, отдельный чертёж свёрнут в рулон на столе. Подходит для *drawing*, *fold*, *roll* и передачи материалов коллеге. |
| [cafe.webp](../public/media/field/cafe.webp) | Бариста протягивает бумажный стаканчик с крышкой. У покупателя в другой руке карта рядом с платёжным терминалом. Подходит для *takeaway cup*, *pay by card* и просьб в кафе. |

## Обложка студии

Для главной страницы в ImageGen создана отдельная горизонтальная иллюстрация в манере цветной гравюры. На ней трамвай идёт по мосту на закате. Версии шириной 1200 и 650 пикселей находятся в `public/media/studio/`.
