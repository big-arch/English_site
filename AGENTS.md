# English Studio

- Учебная PWA. Экраны и API в `app/`, учебная и серверная логика в `lib/`, локальные миграции в `drizzle/`. Настройка окружения и первый локальный запуск описаны в [SETUP.md](SETUP.md).
- Используй `npm run dev` и локальный вход для проверки интерфейса. Из корня запусти `node tests/core.mjs` для результатов упражнений, миграции, лимитов и изоляции прогресса. Для типизации используй `node node_modules/typescript/bin/tsc --noEmit`, для сборки — `npm run build`.
- При правке входа, прогресса и истории проверь два тестовых профиля. Проверь, что уроки доступны при недоступности ИИ, если изменение затрагивает этот сценарий. Ключ ИИ-провайдера хранится на сервере.
